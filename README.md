# 🚀 Fábrica Livre Studio

Uma plataforma ágil, moderna e independente (arquitetura avançada em arquivo único) projetada para transformar ideias faladas ou digitadas em aplicativos web completos e funcionais na velocidade da luz.

## ✨ O que o sistema faz:
- 🧠 **Arquiteto de IA Integrado:** Conectado à nuvem de alta performance (Groq) com engenharia de prompt reversa para evoluir ideias.
- 🎙️ **Comando de Voz (Speech-to-Text):** Dite os comandos e a estrutura do seu aplicativo usando a voz de forma nativa.
- 🎮 **Sistema "Save Game" de Projetos:** Gerencie suas criações em slots organizados com histórico, data e carregamento rápido.
- 💻 **Editor Raio-X (Código Fonte):** Alterne instantaneamente entre a visualização visual e o código HTML puro editável.
- 🌐 **Auto-Hospedagem GitHub (Deploy Instantâneo):** Cria o repositório, injeta o código via API e ativa o GitHub Pages automaticamente gerando o link público do app.
- 📦 **Exportação Física:** Baixe o arquivo `.html` do projeto gerado para o seu dispositivo com um clique.
- 💳 **Monetização Integrada:** Sistema de recargas e Passe Pro com captura automática de retorno de pagamento.
